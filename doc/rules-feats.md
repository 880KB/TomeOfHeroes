## Anzahl Talente
Anzahl ist abhängig von 
- Charakter-Level
  - Anzahl Talente abhängig von Character-Stufe
- Rasse
  - Menschen bekommen 1 Bonus-Talent auf der 1. Stufe
- Klasse
  - Kämpfer bekommen Bonus-Talente aus spezieller Liste
  - Klassen gewähren zusätzliche Talente (s. dort!)

## Voraussetzungen
Voraussetzung kann sein:
- Attributswert
- Klasse (class feature)
- Talent
- Fertigkeit
- Grundangriffsbonus
- other

## Type of Feats
- General Feats
- Fighter Bonus Feats
- Item Creation Feats
- Metamagic Feats

## Repeatable Type
